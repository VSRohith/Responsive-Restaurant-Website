# Responsive Restaurant Website

A modern and responsive restaurant landing page built using HTML, CSS, and JavaScript. The project features a clean user interface, responsive layouts, interactive sections, navigation bar, menu sections, image gallery, customer testimonials, pricing section, and mobile-friendly design.

## Features

- Responsive web design
- Modern UI layout
- Interactive navigation
- Hero section and CTA buttons
- Food menu and pricing cards
- Customer testimonials
- Image gallery
- Mobile-friendly interface
- Clean and structured code

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design

```bash
css/
img/
js/
index.html
README.md
```

## Learning Outcome

This project helped improve frontend development skills, responsive web design concepts, JavaScript interactions, layout structuring, and modern UI implementation using HTML, CSS, and JavaScript.
